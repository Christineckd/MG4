# MG4
## Devlog
After Start(), _time is start equle with _switchSpeed, which is 3.0f. Update() runs every frame and move the sphere up if _up is ture, moving down when _up is false. _timer decreace with Time.deltaTime. If _timer reaches number less than zero,_up will be switch to the oppesite value; so when it used to be up, now it's down; when it used to be down, now it's up.
